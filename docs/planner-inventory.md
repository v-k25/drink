## Architecture and scope

The planner now keeps an ordered array of unique product entries, with raw quantities and changed-size review flags keyed by product ID. Selected categories are unique shopping categories and are independent of browsing and inventory contents. Adding explicitly chooses one pack; repeated add/drop merges into that product's quantity. No serving recommendation or forced swap remains.

The wire shapes (`Product`, `PlannerInput`, `Plan`, `PlannedLine`) and JSON snapshot shape are unchanged. `calculatePlan` permits multiple distinct products in a category, bounds lines by catalogue length, rejects duplicate IDs and empty/missing/extra categories, and retains canonical server prices and safe arithmetic. The sole `actions.ts` change deduplicates saved line categories before existing snapshot validation. No schema, session, auth, catalogue, environment, dependency or global styling changes.

The active-category shelf includes search, show-more, original decorative placeholder art and accessible add buttons. Desktop has an optional native drag/drop target and a sticky scrollable inventory panel. Drops require the internal MIME tag, the current owned drag ID, eligible loaded catalogue membership and a selected category; foreign drops are prevented. Mobile has a fixed subtotal/review bar and a native inventory dialog with the same quantity/remove actions. Final Save/Edit/export navigation is sticky; steps 1/2 have sticky progression bars. Existing saved/new/delete confirmations and real sign-in-required save flow remain.
